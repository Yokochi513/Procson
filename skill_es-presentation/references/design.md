# デザイン詳細（作例）

これは「濃紺＋アクセントブルー＋淡いロー ポリ背景」のビジネス系テンプレートを再現した作例。**利用者のテンプレートに合わせて配色・装飾は差し替える**こと。ここはあくまで型の参考。

## 配色（作例）

| 用途 | 色 | HEX |
|---|---|---|
| メイン（見出し・ヘッダーバー・名刺カード） | 濃紺 | `#17456B` / 濃い側 `#123A5C` |
| アクセント（強調文字・数値・効果カード） | 明るいブルー | `#1E86CB` / 濃い側 `#0E6FB5` |
| 本文テキスト | ダークグレー | `#333333` |
| 背景 | 白〜淡いブルー | `#FFFFFF`→`#EEF4F9` |
| カード枠・区切り線 | ライトグレー | `#E1E8EF` / `#C9D6E2` |
| ハイライト（マーカー） | 淡いブルー | `#BFE0F5` |

**配色の原則**
- メイン色が画面の 60〜70%（構造＝枠・見出し）。
- アクセントは強調のみ。1スライド1〜2箇所まで。使いすぎると効かない。
- 残りは無彩色寄りで情報を邪魔しない。

## 装飾モチーフ（作例）

- 見出し：`▶`（三角マーカー）＋ タイトル ＋ 下線。
- 本文：`●` 箇条書き、強調語はアクセント色・太字。
- 背景：白地に淡いブルーの三角形（ロー ポリ）を四隅に控えめに配置。
- カード：白背景＋薄いドロップシャドウ。見出しは濃紺のヘッダーバー。

装飾は「1つのモチーフを全スライドで繰り返す」と統一感が出る。

## テキストサイズ（作例・HTMLプレビュー基準 / 本文18px以上）

| 要素 | サイズ目安(px) |
|---|---|
| 見出し（自己紹介など） | 32 |
| 名前 | 44 |
| 大学・学部 | 19 |
| 情報ブロック見出し | 19 |
| 情報ブロック本文 | 19（強調語は21） |
| 志望動機の一言 | 46 |
| 志望動機の補足 | 22 |
| 自己PRの強み一言 | 38 |
| 自己PRカード本文 | 21（強調語は23） |
| タグ・英字ラベル・「補足」等の添え字 | 18（最小） |

.pptx では 13.33 インチ幅に載せるため、px を約 0.75〜0.8 倍した pt に換算するとバランスが合う（例：本文19px→約15pt、見出し32px→約26pt）。比率を保つのが目的で、絶対値より見た目の階層が大切。

## 余白（作例）

- スライド外周：上下約7%（52px/720）・左右約5%（64px/1280）。.pptx では約 0.5〜0.65 インチ。
- 見出しと本文の間：34px前後。
- カード同士：24〜26px（.pptx で 0.3〜0.4インチ）で統一。
- カード内側：20〜24px。テキストを枠に接触させない。

## 3レイアウトの構成イメージ

**① 自己紹介**：左に濃紺の名刺カード（大学・学部学科／NAMEラベル／氏名大きく／ローマ字）＋下にタグ。右に情報ブロック3つ（研究内容／研究を通して感じたこと／現在行っていること）を縦積み。

**② 志望動機**：中央寄せ。上に小さめの英字アイブロウ（例 MY MOTIVATION）→ 理由の一言（大きく、キーワードにマーカー）→ 下に補足ボックス（「── 補足」＋20字程度）。

**③ 自己PR**：上に濃紺の帯で強み一言（かぎ括弧はアクセント色）。下に2カラム（「根拠となる経験」／「入社後の活かし方」）。各カードは濃紺／アクセントのヘッダーバー＋本文20字程度、数値や動詞をアクセント色で強調。
