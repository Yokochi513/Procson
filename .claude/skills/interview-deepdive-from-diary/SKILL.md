# 日記から作る面接深掘り質問

日記に書かれた日常の出来事（アルバイト・サークル・勉強・友人関係など）から、面接官が実際に投げかけてくる「深掘り質問」を先回りで作成するスキル。就活生が本番前に自分の頭で考えておくための「予行演習ツール」を作ることが目的であり、模範解答を書いてあげることが目的ではない。

## 目的・スタンス

- **目的**：日記から、面接官が突っ込んでくる質問を先回りで作る。
- **詰問ではなく前向きな問い**にする。「なぜやらなかったんですか？」のような追い詰める言い方ではなく、「〜について、もう少し教えてください」「〜のとき、何を考えていましたか？」のように、本人が話しやすい・振り返りやすい言い方にする。
- **日記に書いていない事実は絶対に作らない。** エピソードの前後関係や心情を推測で埋めない。情報が足りない軸は、質問ではなく「日記に書かれていないので、実際にどうだったか思い出してみましょう」という一言に留める。
- 出力は模範解答ではなく「質問＋考えるヒント」。ヒントは記憶を引き出す誘導であり、答えを代弁しない。

## 入力

就活生が書いた日記（Markdownやテキストなど、日付ごとに区切られた日々の記録）。1日1〜数行の短い記述の集合であることが多い。

## 処理手順

### ステップ1：エピソード候補を抽出する

日記の中から、以下のような「決断・行動・変化」を含む記述を優先的にエピソードとして拾う。単なる予定の記録（「今日は特に何もなかった」等）は対象外とする。

目印になる表現の例：
- 決断・選択：「迷った」「決めた」「〜にすることにした」
- 挑戦・初体験：「初めて」「任された」「一人で」
- 困難・葛藤：「パニックになりかけた」「うまくいかなかった」「大変だった」
- 協働・役割：「教える側になった」「企画係を任された」「友人と協力した」
- 心情の変化：「安心した」「自信になった」「達成感があった」

1つの日記に複数の候補がある場合、**時期の異なる2〜4件程度**（できれば「困難を伴うもの」「役割・責任を伴うもの」「継続的な取り組みが分かるもの」など性質の異なるものを分散させて選ぶ。似た内容ばかり選ばない。

### ステップ2：エピソードごとに5軸で質問＋考えるヒントを作る

各エピソードについて、以下の5軸それぞれで「面接官が聞きそうな質問」を1つと、それに答えるための「考えるヒント」を1つ作る。ヒントは思い出す観点を示すだけで、答えを埋めない。

| 軸 | 何を聞く質問か | ヒントの方向性 |
|---|---|---|
| **動機** | なぜそれに取り組もう／関わろうと思ったのか | 「そのとき他に選択肢はあったか」「なぜそれを選んだのか」を振り返らせる |
| **判断** | 具体的に何を、どう判断・選択したのか | 「一番迷った瞬間はどこか」「その場でどんな基準で決めたか」を思い出させる |
| **困難** | どんな壁・難しさにぶつかったのか | 「日記に書かれている大変さの中身は何だったか」を具体化させる |
| **感情** | そのとき／その後、何を感じたか | 「安心した・自信になった、と書いてあるが、具体的にどんな場面でそう感じたか」を掘る |
| **学び** | そこから何を学び、今どう活きているか | 「その経験は他の場面でも活かせているか」を考えさせる |

書いていない事実に触れる軸（例：日記に感情の記述が一切ない場合の「感情」軸）は、質問を無理に作らず「日記には感情の記述がないため、当時の気持ちを思い出しておくとよい」という注記にする。

### ステップ3：出力フォーマット

Markdownで、エピソードごとに見出しを立てて出力する。

```
## エピソード：〈日記の該当箇所を要約した短いタイトル〉（Day◯・日付）
> 元の記述：「〜」（日記からの引用）

- **動機**：質問／ヒント
- **判断**：質問／ヒント
- **困難**：質問／ヒント
- **感情**：質問／ヒント
- **学び**：質問／ヒント
```

すべてのエピソードを出力したあとに、最後に必ず次のセクションを追加する。

```
## 練習すべき質問トップ3

1. 質問文（どのエピソード由来か／なぜこれが特に深掘りされやすいかを一言で）
2. ...
3. ...
```

トップ3の選定基準（優先順に適用）：
1. **困難・葛藤を含むエピソード**（一貫性・対応力を確認するため面接官が最も深掘りしたがる）
2. **役割・責任（企画係・後輩指導など）を伴うエピソード**（主体性・再現性を確認したがる）
3. **本人の判断が分かれるポイントがあるエピソード**（論理的思考力を確認したがる）
日記の内容が薄く5軸すべてを埋められないエピソードしかない場合は、その旨を正直に伝え、無理に3つ作らない。

## 出力時の注意

- 全体を通して、詰問調（「なぜできなかったのですか」など）を避け、伴走者としての前向きな言葉遣いにする。
- 引用は日記の実際の記述に忠実に。要約であっても内容を誇張・脚色しない。
- 日記内に就活を意識した記述（自己分析・ガクチカ検討など）があれば、それ自体もエピソード候補として扱ってよい。
