# デザインシステム（配色・余白・タイポグラフィ）

就活スライド（①自己紹介／②志望動機／③自己PR）の見た目を一貫させるためのルール。
既定はネイビー × ブルー × ホワイトのコーポレート調。テンプレートが別の配色なら
「配色」の HEX だけ差し替えれば全体が追従する（CSS変数 / `THEME` で一元管理）。

## 配色ルール

| 用途 | 変数名 | 既定 HEX |
|------|--------|----------|
| 見出しボックス／タイトル文字 | `navy` | `#173D63` |
| （予備）濃色バリエーション | `navy2` | `#1F5C8B` |
| アクセント（数値・キーワード・強調） | `blue` | `#1F7FC0` |
| タイトル下線 | `line` | `#2E6FA8` |
| 本文テキスト | `ink` | `#2B2F36` |
| 補足ラベル（大学名・英字など） | `muted` | `#6B7683` |
| カード背景 | `card` | `#FFFFFF` |
| カード枠線 | `card_bd` | `#E3E9F0` |
| ページ背景 | `page` | `#EEF3F8` |
| 隅のローポリ風アクセント | `poly` | `#DCE8F4` |

**使い分けの原則**
- **ネイビー**は「見出し・箱」に使う（面で置く色）。
- **ブルー**は「一番伝えたい数値・キーワードだけ」に限定する。1スライドあたり **2〜3語まで**。
- **本文は黒（ink）**。色数を絞るほどコーポレート感が出る。
- 迷ったら「色を足す」より「色を減らす」。

## 余白ルール

- **スライド外周マージン**：上下 約 5.2%／左右 約 5.6%（四辺を統一）。
- **タイトルと本文の間**：約 3.4%（下線の区切り感を確保）。
- **カード間の間隔（ガター）**：14px（HTML）／0.22〜0.28in（pptx）で統一。
- **カード内パディング**：16〜18px（見出しボックスは 10px）。
- **行間**：本文 line-height 1.5 前後、項目間 9px。
- **原則**：「見出しボックス＋白カード」を1セットとして扱い、
  **セット間の余白 > セット内の余白** にして視覚的なまとまりを作る。

## タイポグラフィ

- 和文フォント：`Yu Gothic`（無ければ Hiragino / Meiryo 等のゴシックにフォールバック）。
- 既定サイズ（pt, pptx基準。全体を大小したいときは `SIZES` を触る）：

  | 役割 | サイズ |
  |------|--------|
  | スライドタイトル | 24 |
  | 氏名 | 30 ／ 英字 13 |
  | 大学・学部学科 | 14 |
  | 専攻タグ | 13 |
  | ボックス見出し | 16 |
  | 本文ブレット | 14 |
  | 大見出し（②③の一言） | 26 |
  | ラベル（POINT / MY STRENGTH） | 13 |
  | 補足文 | 15 |

- タイトルは「▶ ＋ 見出し ＋ 下線」で統一。
- キーワード強調は色（ブルー）＋太字。下線・斜体・複数色の乱用はしない。

## レイアウトの骨格

- 画面比率 **16:9**。
- 全スライド共通：ページ背景 + 右上に淡いローポリ三角 + 「▶タイトル＋下線」 + 左下フッター（英語ラベル＋ドット）。
- **①自己紹介**：プロフィール帯（左ネイビーバー＋大学名＋氏名＋専攻タグ）＋3カード（各カードはネイビー見出し＋白ボディ、箇条書き）。
- **②志望動機**：大見出しカード（左ブルーバー＋ラベル＋一言）＋補足カード（ネイビー見出し＋白ボディ）。
- **③自己PR**：大見出しカード（強みの一言）＋2カード（強みの根拠／入社後の活かし方）。
