# 基本設計書テンプレート（仕様駆動方式）

このテンプレートに沿って基本設計書を出力する。**章は入力された要件定義書の内容に応じて取捨選択する**こと。要件に存在しない章は「該当なし」と書くか省略し、要件に無い章を創作しない。

各章の冒頭ガイド（`>` の行）はテンプレート説明なので、**出力には含めない**。`<...>` は埋める箇所。

トレーサビリティの要点:
- 設計項目には可能な限り **対応要件ID** を併記する（見出し脇、または表の「対応要件」列）。
- 最後の **9. 要件トレーサビリティマトリクス** で全要件のカバレッジを必ず確認する。
