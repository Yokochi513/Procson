# 就活スライド（ES → ①自己紹介／②志望動機／③自己PR）

エントリーシート（ES）と参考デザインから、就活用スライドを作るための成果物一式です。
ネイビー × ブルー × ホワイトのコーポレート調で、**HTMLプレビュー**と
**PowerPoint（.pptx）** の2形態を用意しています。

## ファイル

| ファイル | 用途 |
|----------|------|
| `es-slides.html` | ブラウザで開くだけで見た目を確認できるプレビュー（外部依存なし） |
| `es-slides.pptx` | PowerPoint 版（16:9・3スライド） |
| `README.md` | このメモ |

> スライドの中身は例文（田中太郎さん・IT業界／文系未経験向け）です。
> 実際のお名前・大学名・エピソードに差し替えてお使いください。

## まず見た目を確認する

`es-slides.html` を**ダブルクリックしてブラウザで開く**だけ。
①自己紹介／②志望動機／③自己PR の3スライドが縦に並んで表示されます。
印刷やPDF化もブラウザの「印刷」からできます。

## 中身を自分用に書き換える

### かんたん（HTMLだけ直す）

`es-slides.html` をテキストエディタで開き、本文（`<li>` や `<p>` の中）を書き換えます。

- 強調したい語は `<span class="accent">…</span>` で囲むと**青太字**になります
  （②③の大きい見出しの中では `<span class="em">…</span>`）。
- 配色を変えたいときは、ファイル冒頭 `:root{ … }` の色（`--navy` などの HEX）を変更します。
- ○○大学 などのプレースホルダを実データに置き換えます。

### PowerPoint（.pptx）を作り直す

`.pptx` はスクリプトから生成します（HTMLを手で貼り替えるのではなく、内容を揃えて再生成）。

```bash
pip install python-pptx
# スキルに同梱のスクリプトを使う
python .claude/skills/es-slides/assets/build_pptx.py recruitment-slides/es-slides.pptx
```

スクリプト上部を編集するだけで中身を差し替えられます。

- `DATA` … 本文。文中を `**…**` で囲むと**青太字（アクセント）**になります。
- `THEME` … 配色（HTMLの `:root` と同じ HEX に揃える）。
- `SIZES` … 文字サイズ（全体を大きく／小さく）。

> **注意**：HTML と pptx は必ず同じ内容・配色・サイズに揃えてください
> （片方だけ直すと食い違います）。

## デザイン・文章のルール

一貫性を保つためのルールは、スキル側のドキュメントにまとまっています。

- 配色・余白・文字サイズ … [`.claude/skills/es-slides/references/design-system.md`](../.claude/skills/es-slides/references/design-system.md)
- 各スライドに入れる項目・文字数 … [`.claude/skills/es-slides/references/content-guide.md`](../.claude/skills/es-slides/references/content-guide.md)

要点だけ:

- **色は絞る**：ネイビーは「箱・見出し」、ブルーは「一番伝えたい数値・キーワードだけ」（1枚に2〜3語まで）、本文は黒。
- **一言で言い切る＋約20字の補足**：志望動機・自己PRは結論から。理由は1つに絞る。
- **収まらないときは、文字を小さくする前に文を短くする**。

## Claude に作ってもらう場合

このリポジトリには `es-slides` スキルが入っています。Claude Code で

のように頼めば、テンプレ確認 → HTMLで確認 → OKなら .pptx 書き出し、まで自動で進みます。
明示的に呼ぶときは `/es-slides` でも起動できます。

## よくある質問

- **フォントが違って見える**：既定は `Yu Gothic`。無い環境では別のゴシックに置き換わります。必要なら別フォント名を指定してください。
- **pptx を開くと少しズレる**：PowerPoint / Google スライドで最終確認してください（本文は枠内に自動フィットする設定です）。
- **別のESで作り直したい**：内容（HTMLの本文と `build_pptx.py` の `DATA`）だけ差し替えれば、同じデザインで作り直せます。
