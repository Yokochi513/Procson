# ゲームプレイ設計書：桃太郎ストーリー（v2 追加システム）

[01_基本設計書](01_基本設計書.md) / [02_論理設計書](02_論理設計書.md) / [03_詳細設計書](03_詳細設計書.md) を前提に、
**仲間集め（会話クイズ）→ おとも追随 → 鬼の追跡 → ボス戦（自動カットシーン）→ 鬼退治エンディング** という
桃太郎ストーリー層を定義する。実装は **v2 基盤（buildWorld）が M2 まで通ってから** 着手する。

## 0. 確定した仕様（本設計の前提）
| 論点 | 決定 |
|---|---|
| ボス戦の形式 | **自動カットシーン演出**（仲間が自動で鬼を倒す→勝利→エンディング。プレイヤーは見るだけ） |
| 鬼の出現 | **特定エリアで追跡**（鬼ヶ島エリア内に入ると追跡開始） |
| ゲームオーバー後 | **スポーン地点から再開**（仲間・クイズ進行は保持） |

---

## 1. ストーリー概要
1. プレイヤー（桃太郎）は惑星（＝岡山）を巡る
2. 各地に **犬・サル・キジ** がいる。話しかけると**会話モード**＝**岡山クイズ**が出る
3. 正解すると仲間になり、以後 **モンハンのおとものように追随**する
4. **鬼ヶ島エリア**に入ると **鬼が追跡**してくる。接触すると…
   - 仲間が **3匹未満** → **ゲームオーバー**（スポーンへ戻る）
   - 仲間が **3匹全員** → **ボス戦（自動カットシーン）**で鬼を倒し、**エンディング**
5. クリア：鬼退治成功

---

## 2. ゲーム状態マシン（GameState）
既存の「アニメ状態（idle/walk/run/jump）」とは別レイヤの**ゲーム進行状態**を新設。
```
            話しかけ(E)                 クイズ正解 or 離脱
 explore ───────────────► dialogue ─────────────────► explore
    │                                                     ▲
    │ 鬼接触 & 仲間<3                                      │ オーバーレイ解除
    ├───────────────────────► gameover ──────────────────┘（スポーン再開）
    │
    │ 鬼接触 & 仲間==3
    └───────────────────────► boss(自動カットシーン) ───► ending
```
| 状態 | 操作 | 更新するもの |
|---|---|---|
| `explore` | 通常操作 | 移動・カメラ・仲間追随・鬼追跡・ポータル |
| `dialogue` | UIのみ（移動停止） | 会話/クイズUI。回答で分岐 |
| `boss` | 入力無効 | カットシーン（カメラ・演出の再生） |
| `gameover` | オーバーレイ（クリック/キーで再開） | 停止。解除でスポーン復帰 |
| `ending` | オーバーレイ | 停止。クリア表示 |

> ループ先頭で `gameState` を見て分岐。`explore` 以外では `controller.update` を止め、各状態の更新のみ行う。

## 3. 仲間キャラ（犬・サル・キジ）
### 3.1 配置
- glb（Meshy 製）を各エリアに NPC として配置。未加入時はその場で待機（軽い待機アニメ／ボブ）
- 頭上に「！」等のインタラクト可能マーカー（DOM or スプライト）

### 3.2 加入フロー
```
近接(範囲内) → 案内「はなす(E)」表示 → E → gameState=dialogue
  → 会話イントロ → クイズ出題 → 回答
     ├ 正解(規定数) → successLine → 加入(followers に追加) → gameState=explore
     └ 不正解        → failLine → 再挑戦 or 立ち去る（explore）
```
- 加入済みの仲間には話しかけ不可（または一言セリフのみ）

### 3.3 追随（モンハンおとも風）
- **フォローチェーン**: `player → 仲間0 → 仲間1 → 仲間2` の順で連なる
- 各仲間は「リーダーの後方 `followDistance`」の地点を目標に、球面上を追う
  - 目標点 = リーダー位置から (リーダー→自分) 方向に `followDistance` 戻した点
  - 速度上限つきで補間移動 → **地表へレイキャストして接地**（surfacePatch/planet 流用）
  - 進行方向へ向く（既存 orientToSurface）
  - 離れすぎたら**ワープ補正**（画面外での遅延を防ぐ）
- 停止中はリーダー周囲でゆるく待機

## 4. 会話・クイズモード
### 4.1 UI（DOM オーバーレイ）
- 画面下に会話ボックス（話者名＋セリフ）
- クイズ時：問題文＋**3択ボタン**。選択で正誤判定→次問 or 結果
- `gameState=dialogue` の間は移動・カメラ入力を無効化（キー無視）

### 4.2 判定
- `passRule`：`'all'`（全問正解）または `N`（N問以上正解）
- 正解規定達成→加入、未達→失敗セリフ→再挑戦可能

### 4.3 岡山クイズ例（`quizzes`）
| 仲間 | 問題 | 選択肢 | 正解 |
|---|---|---|---|
| 犬 | 岡山名物のフルーツは？ | 白桃 / りんご / みかん | 白桃 |
| サル | 岡山城の別名は？ | 烏城 / 白鷺城 / 松本城 | 烏城 |
| キジ | 日本三名園で岡山にあるのは？ | 後楽園 / 兼六園 / 偕楽園 | 後楽園 |
| （予備） | 桃太郎が鬼退治に配ったものは？ | きびだんご / おにぎり / まんじゅう | きびだんご |

## 5. 鬼（敵）
### 5.1 出現・追跡（特定エリア）
- `areaLandmarkId`（例：鬼ヶ島＝岡山城エリアを転用 or 新設）内でのみ有効
- プレイヤーがエリア（`anchor·pos > cos(areaAngle)`）に入り、`aggroRange` 以内に近づくと**追跡開始**
- 追跡：鬼→プレイヤー方向へ**接平面移動**（速度 `speed`、プレイヤーより気持ち遅め）・地表接地・進行方向へ向く
- エリア外に十分離れると追跡解除（元位置へ徘徊）

### 5.2 接触判定
```
if distance(player, oni) < contactRadius:
    if followers.length >= 3 → gameState = 'boss'（カットシーン）
    else                     → gameState = 'gameover'
```
- 接触の取りこぼし防止に、毎フレーム距離判定（安価）

---

## 6. ボス戦（自動カットシーン）
### 6.1 発火
- 仲間3匹揃い＋鬼接触（または鬼ヶ島最奥トリガー）→ `gameState='boss'`
- 入力無効化。カメラをカットシーン用に切替

### 6.2 演出タイムライン（例・秒）
```
0.0  カメラが 桃太郎＋3匹＋鬼 を捉える（引き）
0.5  「いくぞ！」テロップ
1.0  犬 → 鬼へ突進（attack クリップ or 手続き移動）
1.8  サル → 追撃
2.6  キジ → 空から突撃
3.4  鬼がのけぞる（scale/rotation 演出）→ 倒れる/縮小フェード
4.5  「鬼退治 成功！」→ gameState='ending'
```
- glb に attack クリップがあれば AnimationMixer で再生、無ければ**手続きアニメ**（突進・のけぞり・フェード）
- 実装は「タイムライン配列（t, action）」を毎フレーム進める簡易シーケンサ

### 6.3 エンディング
- クリア画面（DOM）：メッセージ＋「もう一度」ボタン等。`bossDefeated=true`

---

## 7. ゲームオーバー → スポーン再開
- `gameover` オーバーレイ表示（「鬼につかまった…」）
- クリック/キーで解除 → **プレイヤーをスポーンへ**、鬼を元エリアへリセット、`gameState='explore'`
- **保持**：加入済み仲間・クリア済みクイズ（親切設計）。仲間はプレイヤー近くへワープ

## 8. データ設計（マニフェスト拡張）
`world/manifest.ts` に追加する型。
```ts
export interface CompanionDef {
  id: string;                 // 'dog' | 'monkey' | 'pheasant'
  name: string;               // 表示名（犬/サル/キジ）
  model: string;              // glb url
  targetHeight: number;
  landmarkId: string;         // 出現エリア
  local: [number, number];    // エリア内 (x,z)
  quizId: string;             // 加入クイズ
  followDistance?: number;    // 追随間隔（既定 1.4）
  clips?: { idle?: string; walk?: string; run?: string; attack?: string };
}
export interface QuizQuestion { q: string; choices: string[]; answer: number; }
export interface QuizDef {
  id: string; intro: string;
  questions: QuizQuestion[];
  passRule?: 'all' | number;  // 既定 'all'
  successLine: string; failLine: string;
}
export interface EnemyDef {
  id: string;                 // 'oni'
  model: string; targetHeight: number;
  areaLandmarkId: string;     // 追跡有効エリア（鬼ヶ島）
  areaAngleDeg: number;       // エリア判定の角半径
  spawnLocal: [number, number];
  speed: number;              // 追跡速度（例 6：プレイヤー7より遅い）
  aggroRange: number;         // 追跡開始距離（例 8）
  contactRadius: number;      // 接触=判定距離（例 1.0）
  clips?: { idle?: string; walk?: string; hit?: string };
}
// WorldDef へ追加
export interface WorldDef {
  /* …既存… */
  companions?: CompanionDef[];
  quizzes?: QuizDef[];
  enemies?: EnemyDef[];
}
```
### 8.1 実行時ストーリー状態
```ts

```

## 10. ゲームループ統合（擬似コード）
```
switch (story.state) {
  case 'explore':
    controller.update(dt,input,camera)
    cameraRig.update(...)
    companions.update(dt)      // 追随
    oni.update(dt)             // エリア内なら追跡＋接触判定 → 状態遷移
    portals.update(pos)
    checkTalk(input)           // 近接＆E → dialogue
    break
  case 'dialogue': quizUI.update(); break         // 入力はUIへ
  case 'boss':     bossCutscene.update(dt); break // 演出進行
  case 'gameover': if (dismiss) respawn();  break
  case 'ending':   /* 待機 */ break
}
player.animate(state); postfx.render()
```

## 13. 受け入れ条件・検証方法
- **状態遷移**: explore↔dialogue、接触→gameover/boss、boss→ending が正しく遷移（数値/ログ検証）
- **加入**: クイズ正解で `followers.length` が増え、追随が始まる
- **追随**: 各仲間がリーダーから `followDistance±α` を保ち、地表に接地（半径≈R+feet）
- **鬼追跡**: エリア内で距離が縮む、`contactRadius` で状態遷移。エリア外で解除
- **ゲームオーバー**: プレイヤーがスポーンへ、仲間・クイズ進行は保持
- **ボス**: 仲間3匹接触でカットシーン再生→ending、`bossDefeated=true`
- 恒常：型チェック通過・`npm run build` 成功・コンソールエラーなし

## 14. 決め事・拡張余地
- **鬼ヶ島の場所**: 既存「岡山城エリア」を鬼ヶ島に転用 or 南極（未使用）に新設。マニフェストで指定
- **クイズ難度/数**: 1〜2問／仲間を既定。増減はデータで
- **カットシーン演出**: まずは手続きアニメ（突進・のけぞり・フェード）で成立させ、glb にクリップがあれば差し替え
- **音**: 加入・被弾・勝利の効果音は SG-5 の任意拡張
- **セーブ**: 進行の永続化は範囲外（リロードで初期化）
