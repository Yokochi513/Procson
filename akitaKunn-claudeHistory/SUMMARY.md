## 1. 就活Tool（Next.js Webアプリ）

このリポジトリの `shuukatsu-app` にあたるプロジェクト。「既存デザインは変更しない / 不足しているファイルだけ追加 / 既存コードをできるだけ再利用 / 変更前に関連ファイルを読む」という方針で進行。

**実施内容**
- エントリーシート（ES）を書ける欄を追加
- フィードバックページを追加し、デザインを就活サイト風に刷新
- アプリ名を「就活Tool」に変更。ESを利用した面接練習機能を追加
- Claude API の無料枠・課金について相談し、課金せずAPI部分の構造だけ先に入れる方針を選択
- 音声認識機能の導入

**最終成果: AI面接チャット画面**
- `/interview` に「AI面接官と会話形式で面接する」カードを追加し、`/interview/chat` へ遷移
- 新規ファイル: `app/interview/chat/page.tsx`、`lib/interview/chatScript.ts`
- 面接官アバター（差し替え可能なSVG、発話中は口が動く）、面接状況のリアルタイム表示、チャット形式の会話、回答入力欄＋送信ボタン
- Web Speech API（`SpeechSynthesisUtterance` / `lang: "ja-JP"`）で面接官のセリフを自動読み上げ。発話終了で入力欄が有効化。未対応ブラウザではテキストのみで進行
- 進行スクリプト（入室 → お名前 → 自己紹介 → ガクチカ → 志望動機・自己PR・弱み・失敗経験・チームワーク・将来・最後の一言）を実装し、ブラウザで動作確認済み

## 2. カラオケ採点分析アプリ `test42.py`（Python / customtkinter）

セッション数・分量ともに最多。CSVの採点データを読み込んで分析する自作デスクトップアプリの継続的な改良。

**バグ修正**
- カレンダー機能の不具合（日付と曜日のズレ）

**機能追加**
- 技法フィルタの範囲検索（XX〜YY形式）
- レーダーチャート（聴感・チャート合計・5値）の表示整理、ラベルの二重表示解消
- 音域・声域とピアノ表示の上下入れ替え
- 曲ごとのタグ・メモ機能（保存・削除・色変更、スクロール対応）
- 歌唱履歴の表示位置修正、カンスト何曲目かの表示
- フルスクリーンモード（メイン画面・採点詳細画面）
- 詳細欄でのハートタイプ検索、音域・声域の手動検索・音名検索
- 歌手名が長い場合の省略表示（65文字以降を `...`）
- 検索の「もしかして」候補提案（CSVから近い曲名を抽出して再検索）
- 採点画面・統計画面を新規ウィンドウを作らずに表示
- 一度実装後に削除したもの: Apple Music連携、ライトモード、歌った場所の登録、簡易音域表示画面

**デザイン**
- customtkinter の枠を発光させる高クオリティ化
- 背景の大改造（バーチャル / 森 / 海 / 近未来 / 日本風の夜の海 / 宇宙風）。フォントは BIZ UDGothic を維持
- 最終的にWebダッシュボード風のモダンUIへ（丸角カード、ピル型チップ、サイドナビ、ドロップダウンのテーマ切替）

**配布**
- PyInstaller で exe 化。配布はしない前提で、`dist` は削除しても `test42.py` から再ビルド可能と確認

**アイデア出し**
- 「他にアイデアありますか？」の繰り返しにより、**140件超の機能アイデア**が提案として蓄積（ドラッグ＆ドロップCSV読み込み、個人目標設定、検索欄クリアボタン、キーボード操作、検索条件プリセット保存など）

## 3. Minecraft統合版アドオン「Sky Citadel（天空の城）」

スマホ対応の Bedrock Edition 向け超大型エンドコンテンツ。全体1000〜1500ブロック、浮遊島15〜20個、巨大建築10〜15棟という規模。

**進め方**
- Phase1〜10で仕様を設計 → 仕様書として採用し実装フェーズへ
- 実装ルール: 推測禁止 / Microsoft Learn・Vanilla Behavior Pack準拠 / 最新Script API使用 / 非推奨API不使用 / スマホでの動作を考慮
- 作成順: manifest.json → behavior_packs → resource_packs → entities → loot_tables → structures → features → feature_rules → spawn_rules → functions → scripts → sounds → texts

**トラブルシューティング**
- Bedrock 1.21.203（26.32）で Content Log エラーを0件になるまで修正（`say` の構文、spawn_rules の最新仕様対応、entity JSON の format_version、`sky_golem.entity.json` の animation_controllers の位置）
- `function setup` が見つからない、zipアーカイブが無効、実験的機能の要否などの問題を解決
- モブのテクスチャを自作
- 特定バイオームでの自然湧きを止め、ダンジョン内のみに限定

**最終成果: `SkyCitadel_v0.11.0.mcaddon`（65.6KB / JSONエラー0）**
- 自動発動・1回限り・リログ耐性つきの4イベントを実装
  1. **大聖堂の試練**: 入場でバリア封鎖、天空騎士4＋天空魔導士1を撃破で解除＋島の鍵
  2. **闘技場ウェーブ戦**: 金ブロックに乗ると開始。Wave1近衛兵4 → Wave2騎士2＋近衛2 → Wave3天空ゴーレム
  3. **橋崩落トラップ**: 東幹線橋を渡ると背後が3段階で崩落（予兆あり・理不尽な即死なし）
  4. **封印儀式**: 4本柱を北西→北東→南西→南東の順で点灯。誤るとリセット＋ガーゴイル襲来
- 攻略動線: 大門 → 大橋 → 各島で鍵集め → 鍵5個で中央核ゲート開錠 → 封印区域の儀式 → 王城 → 4フェーズのラスボス戦（ボスゲージつき）

**残タスク**
- BGM・環境音の .ogg 2ファイル
- 図書館・崩壊区域・居住区の鍵3箇所のコマンドブロック手動設置
- 装飾の作り込み → ストラクチャーブロック保存 → `structure_template_feature` による自然生成化
- Phase10チェックリストの通しプレイ（ボス戦のリログ復帰・マルチプレイ検証）
